# 家庭维修预约调度

端口规划：`5114`

```bash
npm install
npm run dev    # 开发
npm test       # 自动化测试（node:test，覆盖创建/冲突/流转/筛选排序/统计/异常恢复）
npm run build  # 构建
```

功能：

- 业主与维修人员维护（名下有工单时禁止删除）
- 创建工单：选业主、人员、日期、时段（上午/下午/晚上）与紧急程度
- 同一人员同一日期同一时段只能接一单，冲突会提示并可改期/改派；重复预约只保留一次
- 工单状态单向流转：待确认 → 已预约 → 已上门 → 已完成，完成时填写回访结果
- 列表按日期、人员、状态、关键词组合筛选，可按预约时间或紧急程度排序
- 统计：今日待上门、本周预约、冲突次数、每位人员工单量（进行中/全部）
- 数据保存在 localStorage，刷新不丢；数据损坏或存储失败时降级为空数据并提示，不崩页
